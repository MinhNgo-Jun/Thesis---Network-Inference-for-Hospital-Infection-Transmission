### Thesis - Network Inference for Hospital Transmission
##### Develop statistical framework for identify the transmission network between wards in hospital system, using the sparse, temporal autocorrelation count data. Application to hospitals, approved by Alfred Health Human Research Ethics Board (Local reference number 445/21)
##### Main tasks are:
##### - Develop a model for handling the Zero-infalted Poisson data and estimate the precision matrix for identifying the structure of the network (Extend the original ZIPLN and apply Gaussian graphical model with MCMC algorithms for high-dimensional data).
##### - Compare with the existing Bayesian Mixed Graphical Model (BMGM - Florez, et al. 2025) and apply to the real data
